# ADR-0009: 평가용 공고 2건 — S-OIL 사무직(55189170), 오리온 생산직(55162188)

- 상태: 채택
- 날짜: 2026-10-12
- 관련 스펙: 01 (관찰 9장), 02·03 (입력 데이터)

## 맥락

전처리·스코어링을 검증하고 목업 지원자(공고당 완벽 2, 부분 3, 미스매치 1)를 만들 기준이 될 실제 공고 2건이 필요하다. 수집기로 후보 공고를 받아 보며 다음이 드러났다.

- 사람인의 "이미지 공고" 중에도 이미지가 **안내 배너**일 뿐 요건이 없는 공고가 있다 (55238467).
- 신입 공채는 요건이 학력·졸업시기 정도로 적어 지원자 변별이 어렵다 (54975614).
- 사람인 템플릿으로 작성된 **텍스트 공고**도 많다 (55240589).

선정 기준 (수집 관찰로 보강):

1. 본문이 이미지일 것 (텍스트 공고 제외)
2. **이미지 안에 자격요건·우대사항이 있을 것** (안내 배너·외부 링크형 제외)
3. 지원자를 완벽/부분/미스매치로 가를 수 있을 만큼 요건이 있을 것
4. 두 공고의 직군이 서로 다를 것

## 결과

- 얻는 것: 두 공고가 직군(사무 vs 생산)·학력 기준(대졸 vs 고졸)·요건 성격(어학·전공 vs 근무 가능 조건·경험)이 뚜렷이 달라, 직군 무관 일반화를 확인하기 좋다. 이미지 레이아웃도 달라(860px 세로 3170 vs 720px 세로 1890, 병합 셀 표 vs 4열 표) 전처리의 일반성을 시험할 수 있다.
- 감수하는 것:
  - 두 공고 모두 **경력 요건이 약하다** (A 신입, B 경력 무관·경험 우대). 연차 계산 같은 경력 매칭은 이 데이터로 충분히 검증되지 않는다 → 목업 지원자 설계에서 "해당직무 근무경험" 우대를 활용하고, 한계로 기록한다.
  - B의 "국가보훈대상자" 우대 같은 **법정 우대 항목**은 민감 속성이다 → 스코어링 반영 방식은 스펙 03에서 정한다.
  - 공고는 마감되면 사라진다 (A D-2, B D-8). 원본은 로컬 스냅샷으로 보존한다 (ADR-0005, ADR-0007).
