# ADR-0017: 점수식 — 필수·우대 가중 평균 × 필수 미충족 게이트, "모름"은 절반

- 상태: 채택 (상수는 실험 Y2로 보정)
- 날짜: 2026-10-12
- 관련 스펙: 03

## 맥락

- 판정 상태 5가지(`met`/`partial`/`unmet`/`unknown`/`not_applicable`)를 0~100점 하나로 바꿔야 한다 (ADR-0015).
- 요건 수가 공고마다 다르다 (B 필수 2·우대 2, A 분야별 필수 5~6·우대 2).
- 필수 요건 미충족은 크게 깎여야 하지만, 추출·판정 단계에 오류가 있을 수 있다.
- 입사지원서로 확인하기 어려운 필수 자격("해외여행 결격사유 없음")이 있다 — 정보가 없다는 이유로 미충족 처리하면 대부분의 지원자가 같은 이유로 깎인다.
- 점수는 요건별 기여로 분해되어 설명돼야 한다.

## 결정

```
s:     met 1.0 · partial 0.5 · unknown 0.5 · unmet 0 · not_applicable → 계산에서 제외
M = 필수 요건 s의 평균      P = 우대 요건 s의 평균   (sensitive 요건 제외, ADR-0018)
base  = 0.7·M + 0.3·P      (우대 요건이 없으면 base = M, 필수가 없으면 base = P)
gate  = 0.8 ^ (unmet 필수 개수)
score = 100 · base · gate  → 표시는 반올림 정수
기여(요건 i) = 100 · gate · w_group · s_i / n_group     (w_group = 0.7 또는 0.3)
```

- **요건 수로 나눈 평균**: 요건이 많은 공고와 적은 공고의 점수 척도를 맞춘다. 요건 하나의 무게는 요건 수에 반비례한다.
- **필수 0.7 / 우대 0.3**: 필수를 모두 충족하고 우대가 하나도 없으면 70점 — "자격은 되지만 강점은 없음". 필수를 모두 충족하면 우대가 아무리 없어도 필수 하나를 놓친 지원자보다 높게 둔다.
- **소프트 게이트 0.8^k**: 필수 미충족 하나로 0점을 만들지 않는다. 판정 오류 하나가 지원자를 지우는 대신 크게 깎고, 사유를 근거표에 남긴다.
- **unknown = 0.5, 게이트 없음**: "모름"은 "없음"(0)도 "있음"(1)도 아니다. 별도로 "확인 필요"로 보여 면접·서류 확인으로 넘긴다.
- **not_applicable 제외**: "남성의 경우 병역필"은 여성 지원자에게 분모에서 빠진다.
- **분야별 계산 후 최고**: 모집분야마다 적용 요건이 다르므로 분야별로 계산하고 대표 점수는 최고값.
- 상수(0.7/0.3, 0.8, 0.5)는 `scoring.score.Weights` 한 곳에 두고 결과 파일에 함께 저장한다.

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| 필수 미충족 → 0점 (하드 컷) | 판정 오류 하나에 지원자가 사라진다. 순위 정보가 없어져 "아깝게 떨어진 지원자"를 보지 못한다 |
| 필수 미충족 → 필터만 하고 점수는 따로 | 결과가 두 축으로 나뉘어 0~100 랭킹 요구와 맞지 않는다 |
| 요건마다 고정 가중치 (필수 3, 우대 1)의 합 비율 | 요건 수가 많은 공고에서 우대 비중이 커지고, 공고마다 "필수만 충족" 점수가 달라진다 |
| unknown = 0 | "해외여행 결격사유 없음"처럼 이력서에 잘 쓰지 않는 자격 때문에 모두가 깎인다. 정보 부족을 결격으로 취급하게 된다 |
| unknown → 분모에서 제외 | 정보가 적은 이력서일수록 유리해진다 (빈 이력서가 높은 점수) |
| 유형(category)별 가중치 | 유형이 같아도 공고마다 중요도가 다르다. 공고가 필수/우대로 이미 중요도를 말하고 있다 — 공고에 없는 판단을 더하지 않는다 |

## 결과

- 얻는 것: 점수가 판정에서 결정적으로 나오고, 기여 합 = 점수로 분해된다. 가중치 변경은 재호출 없이 재집계.
- 감수하는 것:
  - 상수는 근거가 약한 선택이다 → 목업 12명의 의도 라벨 구간(완벽 ≥ 85, 부분 40–84, 미스매치 < 40)으로 보정하고 결과를 기록한다 (실험 Y2). 목업에 맞춘 보정이라는 한계를 README에 적는다.
  - 요건이 적은 공고(B)에서는 요건 하나의 판정이 점수를 크게 움직인다.
