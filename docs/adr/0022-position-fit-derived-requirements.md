# ADR-0022: 직무 요건이 없는 공고는 모집분야 이름에서 '직무 적합도' 우대 요건을 도출한다

- 상태: 채택
- 날짜: 2026-10-12
- 관련 스펙: 05 (03의 확장)
- 관련 ADR: [0008](0008-image-only-conditions.md) (조건은 이미지에서만), [0017](0017-score-formula.md) (점수식)

## 맥락

- 공고 55240124(KT&G 계약사원)의 이미지에는 지원자격이 "해외여행 결격사유 없음", "남성의 경우 병역필" 두 가지뿐이고, 직무별 요건은 "채용 홈페이지에서 확인"이라고만 적혀 있다. 모집분야는 29개(브랜드 디자인, 재무운영 지원, 실험실 보조 …)가 이미지에 있다.
- 결과: 공통 자격만으로 점수가 매겨져 학력·병역을 적은 지원자는 모두 100점, 분야 점수도 모두 같아 "대표 분야"가 의미 없이 첫 분야로 표시됐다.
- 지금까지의 원칙은 "공고에 쓰인 것만 조건으로 쓴다"(ADR-0008)였다. 요건을 지어내지 않는 대신 이런 공고에서는 변별력이 없다 (스펙 03 Y3에서도 관찰).

## 결정

1. **언제**: 공고에 모집분야가 있고, 점수에 쓰는 요건 중 **직무 관련 요건이 하나도 없을 때만** 켠다. 직무 관련 요건 = 유형이 경력·기술·직무 지식·자격증이거나, 일부 모집분야에만 걸린 요건. S-OIL(분야별 전공·엔지니어 자격증)과 오리온(해당직무 경험)은 해당하지 않아 결과가 바뀌지 않는다.
2. **무엇을**: 모집분야마다 우대 요건 하나 — `'{분야 이름}'({직무}) 직무 관련 경력·전공·자격`, 범위는 그 분야. 재료는 이미지에서 읽은 모집분야 이름·직무뿐이다 (ADR-0008의 "이미지에서만"은 유지, "공고에 명시된 것만"은 이 경우에 한해 완화).
3. **어떻게 보이게**: `derived_from_position` 표시("모집분야에서 도출 — 공고에 명시된 요건이 아님"), 결과의 공고 안내(`notes`)에 도출 사실과 분야 수를 적는다. 판정은 다른 요건과 똑같이 이력서 인용을 남긴다.
4. **끌 수 있게**: `Weights.use_derived`(기본 켬). 끄면 도출 요건은 점수·확인 필요 수·요약에서 빠진다 — 저장된 판정으로 재집계하므로 LLM 호출 없음.
5. **우대로만**: 필수로 두지 않는다 — 공고가 요구한다고 말하지 않은 것을 탈락 사유로 만들지 않는다. 점수식(ADR-0017)에서 우대 비중은 30%다.

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| 아무것도 하지 않고 정보 부족 안내만 | 정직하지만 순위가 의미 없다. 안내(스펙 05의 A)는 함께 한다 |
| 모든 공고에 도출 요건 추가 | 공고가 이미 직무 요건을 말할 때는 중복이고, 검증을 끝낸 S-OIL·오리온 결과를 흔든다 |
| 도출 요건을 필수로 | 공고가 요구하지 않은 조건으로 지원자를 깎는다 |
| 채용 홈페이지의 직무 상세를 추가 수집 | 사람인 밖 사이트 크롤링 — 범위·법적 부담 (ADR-0004의 수집 범위를 넘음) |
| 직무 적합도를 별도 점수 축으로 | 0~100 랭킹 하나라는 요구와 맞지 않고, 두 점수를 어떻게 합칠지 다시 정해야 한다 |

## 결과

- 얻는 것: 직무 정보가 없는 공고에서도 지원자 배경과 분야가 맞는지로 점수와 대표 분야가 갈린다. 도출 사실이 화면·결과에 남는다.
- 감수하는 것:
  - "공고에 명시된 것만"이라는 단순한 원칙에 예외가 생긴다 — 예외의 조건과 표시를 이 ADR로 고정한다.
  - 모집분야가 많으면 판정 프롬프트가 길어진다 (KT&G 29개 → 지원자당 요건 31개, 호출 수는 그대로 1회).
  - 분야 이름만으로 판단하므로 판정이 거칠다 — 이력서 인용으로 확인할 수 있게 둔다.
