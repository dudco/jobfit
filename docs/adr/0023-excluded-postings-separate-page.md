# ADR-0023: 처리할 수 없는 공고는 기본 화면에서 빼고 별도 주소(`/excluded`)에서만 보인다

- 상태: 채택
- 날짜: 2026-10-12
- 관련 스펙: 05 (04의 확장)

## 맥락

- 텍스트 공고(본문 이미지 없음)나 이미지에 자격요건이 없는 공고는 조건을 만들 수 없다 (ADR-0008). 공고 55226797이 그 예다.
- 이런 공고가 기본 화면의 공고 탭에 섞이면, 열 때마다 "평가할 요건 없음"만 보인다. 채용 담당자가 보는 화면은 평가 가능한 공고만 다루는 편이 낫다.
- 그래도 "왜 이 공고는 없는가"는 확인할 수 있어야 한다 (수집은 됐으므로).

## 결정

- `GET /api/postings`는 평가 가능한(`suitable`) 공고만 돌려준다.
- `GET /api/excluded`가 처리하지 않은 공고와 이유를 돌려준다: 스냅샷에 본문 이미지가 없음(본문 텍스트 길이 포함), 또는 조건을 추출했지만 요건이 없음(추출 경고).
- `/excluded` 페이지가 이 목록을 보여준다. **기본 화면에는 링크를 두지 않는다** — 주소를 아는 사람만 들어간다 (README에 주소를 적는다).
- 한 번에 실행(`run`)으로 텍스트 공고를 넣으면 지금처럼 이유와 함께 멈춘다 (ADR-0021).

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| 기본 화면에 회색으로 표시 | 요청: 다른 주소로 접근해야 보이게 |
| 아예 목록에서 지움 | 수집한 사실과 제외 이유를 확인할 방법이 없어진다 |
| 쿼리 파라미터(`/?excluded=1`) | 같은 페이지 상태가 둘로 갈려 화면 코드가 복잡해진다. 별도 페이지가 단순하다 |

## 결과

- 얻는 것: 기본 화면은 평가 가능한 공고만. 제외 이유는 한 곳에서 본다.
- 감수하는 것: 기본 화면만 보는 사람은 제외된 공고가 있다는 것을 모른다 — README와 CLI(`jobfit postings`)로 안내한다.
