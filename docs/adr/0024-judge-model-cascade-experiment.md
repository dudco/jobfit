# ADR-0024: 판단 전용 모델(JEV)로 요건 판정을 대신하거나 단계식으로 쓸지 실험으로 정한다

- 상태: 제안 (실험 대기)
- 날짜: 2026-10-12
- 관련 스펙: 06
- 관련 ADR: [0015](0015-judge-then-aggregate.md) (판정은 LLM, 점수는 코드)

## 맥락

- 요건 판정은 정해진 5개 선택지에서 고르는 일이고, 점수는 이미 코드가 계산한다 (ADR-0015). 판정에 글 생성이 꼭 필요하지는 않다.
- 판단 전용 모델은 선택지 확률·확신도만 돌려주고, 상위 LLM보다 훨씬 싸고 빠르다고 알려져 있다. 지금 규모(12명 × 공고 3개, 약 $0.3/공고)에서는 비용 문제가 없지만, 지원자가 수천 명이면 판정 비용·지연이 커진다.
- 이 서비스의 핵심은 **근거 인용**인데, 판단 전용 모델은 글을 쓰지 않는다.

## 결정 (제안)

1. 기본 판정 경로(gpt-4.1)는 바꾸지 않고, 같은 판정을 JEV로 해 **기준과 비교하는 실험**을 먼저 한다 (스펙 06).
2. 근거 인용은 "근거가 되는 이력서 줄"을 줄 번호 선택지로 물어 얻는다 — 인용이 이력서 원문에서 나오는 것이 구조적으로 보장된다.
3. 실험 결과로 다음 중 하나를 정한다: (a) 대체, (b) 확신도가 낮은 지원자만 gpt-4.1로 넘기는 단계식, (c) 채택하지 않음.

## 검토한 대안

| 대안 | 기각·보류 이유 |
|---|---|
| 바로 JEV로 교체 | 한국어·전문 지식 판단 품질을 모른다. 근거 사유 문장이 사라진다 |
| 실험 없이 확장 방향으로만 기록 | 키가 있어 실험 비용이 작다 (세 공고 전체 1센트 미만 추정) |
| gpt-4.1-mini로 단계식 | 스펙 03 Y1에서 근거 없는 추론·인용 문제로 이미 기각 |

## 결과

- 얻을 수 있는 것: 대규모 지원자에서 판정 비용·지연 감소, 확률 기반 확신도(확인 필요 판단에 활용 가능).
- 감수할 것: 판정 사유 문장이 없다 (확신도와 근거 줄만). 이력서가 또 다른 외부 업체로 전송된다 — 운영 시 개인정보 처리 위탁 대상 추가 (data-ingestion-via-customers.md 5장).
