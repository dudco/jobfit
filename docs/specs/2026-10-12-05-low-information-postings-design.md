# 05. 정보가 부족한 공고 대응 설계

- 날짜: 2026-10-12
- 상태: 구현 완료 (실제 판정 확인 대기)
- 단계: ③ 스코어링 + 진입점 (스펙 03·04의 확장)
- 구현 계획: [plans/2026-10-12-05-low-information-postings.md](../plans/2026-10-12-05-low-information-postings.md)
- 관련 ADR: [0022](../adr/0022-position-fit-derived-requirements.md), [0023](../adr/0023-excluded-postings-separate-page.md), [0008](../adr/0008-image-only-conditions.md), [0017](../adr/0017-score-formula.md)

## 1. 배경 — 사용자 확인 중 나온 공고 두 건

| 공고 | 상황 | 문제 |
|---|---|---|
| 55240124 KT&G 계약사원 | 이미지의 지원자격이 공통 자격 2개뿐 ("해외여행 결격사유 없음", "남성의 경우 병역필"). 직무 요건은 "채용 홈페이지에서 확인". 모집분야 29개 | 대졸·병역을 적은 지원자는 모두 100점, 모든 분야 점수가 같아 대표 분야가 첫 분야("브랜드 디자인")로 표시 |
| 55226797 고려대 세종캠퍼스 | 본문이 텍스트(1,722자), 본문 이미지 없음 | 조건 0개 — 기본 화면의 공고 탭에 섞여 "평가할 요건 없음"만 보임 |

## 2. 요구사항

| # | 요구사항 |
|---|---|
| A1 | 공고 수준 안내(`MatchResult.notes`): 직무 요건이 없어 공통 자격만으로 매겼거나, 직무 적합도를 도출했음을 알린다 |
| A2 | 지원자의 평가 분야 점수가 모두 같으면 대표 분야 대신 "전 분야 동일"로 표시 (`CandidateScore.tied_positions`) |
| B1 | 직무 관련 요건이 없는 공고에서만, 모집분야마다 "직무 관련 경력·전공·자격" 우대 요건을 도출해 판정·집계 (ADR-0022) |
| B2 | 도출 요건은 `derived_from_position` 표시, 판정 결과에 `derived: true` |
| B3 | 가중치 `use_derived`(기본 켬)로 끌 수 있고, 끄면 점수·확인 필요 수·요약에서 빠진다 (재집계, LLM 호출 없음) |
| C1 | 기본 공고 목록(`/api/postings`)은 평가 가능한 공고만 |
| C2 | `/api/excluded` + `/excluded` 페이지 — 처리하지 않은 공고와 이유. 기본 화면에는 링크 없음 (ADR-0023) |
| D1 | 점수 계산 방식이 바뀌었으므로 예전 결과(`scoring_version` 1)는 재사용하지 않고 다시 계산 (판정은 캐시) |

## 3. 설계

### 직무 관련 요건 판정 (`scoring/derive.py`)

```
needs_position_fit(criteria) =
    모집분야가 있다
    AND 점수에 쓰는 요건(sensitive 제외) 중 어느 것도
        유형 ∈ {experience, skill, domain_knowledge, certification} 이 아니고
        일부 모집분야에만 걸리지 않는다 (모든 분야에 걸리거나 범위 없음)
```

| 공고 | 직무 관련 요건 | 도출 |
|---|---|---|
| S-OIL | 분야별 전공(일부 분야), 엔지니어 자격증(certification) | 안 함 |
| 오리온 | 해당직무 근무경험(experience) | 안 함 |
| KT&G | 없음 (해외여행·병역 = other) | 모집분야 29개 → p1~p29 |

도출 요건: `id = p{n}`, `text = '{이름}'({직무}) 직무 관련 경력·전공·자격`, 우대, `experience`, 범위 = 그 분야, 근거 = 모집분야 이름(이미지 조각 위치 없음).

### 점수

- 도출 요건은 일반 우대 요건과 같이 집계된다 (ADR-0017). `use_derived = false`이면 상태 점수 `credit = None`(해당 없음과 같은 처리) — 분모·분자·확인 필요 수·요약에서 빠진다.
- 대표 분야: 분야별 점수 최고. 모두 같으면 `tied_positions = true`.

### 안내 문구 (`notes`)

| 조건 | 문구 |
|---|---|
| 도출함 | 공고 이미지에 직무 관련 요건이 없어, 모집분야 N개의 이름에서 '직무 적합도' 우대 요건을 도출해 반영함 — 공고에 명시된 요건이 아님 (가중치에서 끌 수 있음) |
| 도출할 모집분야도 없음 | 공고 이미지에 직무 관련 요건이 없어 공통 자격만으로 점수를 매김 — 지원자 간 점수 차이가 작을 수 있음 |

### 화면

- 랭킹 위 "ℹ 공고 정보" 알림, 분야 칸 "전 분야 동일", 가중치 영역에 "모집분야 적합도 반영" 체크박스(도출 요건이 있을 때만), 도출 요건 판정에 "⚑ 모집분야에서 도출" 배지(설명 포함).
- 지원자 상세의 분야별 점수는 높은 3개 + "그 외 N개 분야 점수"로 요약 (29개 나열 방지).
- `/excluded`: rec_idx · 공고(사람인 링크) · 이유 · 수집 시각.
